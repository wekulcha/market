# Channel subscriptions bot

Автономный Telegram-бот для отслеживания подписок и отписок в канале.

## Запуск локально

```bash
cd bots/channel_subscriptions_bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Токен уже задан в `config.py` как значение по умолчанию. Если нужно переопределить его без изменения кода, создай `.env` по примеру `.env.example`.

## Запуск через Docker Compose

Из корня проекта:

```bash
docker compose up -d channel_subscriptions_bot
```

## Как пользоваться

1. Напиши боту `/start` в личные сообщения.
2. Добавь бота администратором в канал.
3. После привязки бот пришлет сообщение "Канал привязан".
4. Новые подписки и отписки будут приходить владельцу в личные сообщения.

## Команды

- `/start` - запомнить тебя как владельца.
- `/channels` - показать привязанные каналы.
- `/help` - краткая помощь.

Админ-команды доступны только пользователю `1038155901`. Для остальных пользователей бот молча игнорирует эти команды.

- `/users` - показать всех пользователей, которых бот знает по `/start` и событиям подписки/отписки.
- `/usersubs <user_id>` - показать активные подписки пользователя по последним событиям в логах. Пример: `/usersubs 1038155901`.

## Важно

- Процесс бота должен быть постоянно запущен. Если он остановлен, Telegram-события не обрабатываются.
- Telegram не отдает историю старых подписок, только события после добавления бота.
- Бот должен быть именно администратором канала.
- Если канал не привязался, напиши `/start` в личку боту и заново добавь его администратором в канал.
